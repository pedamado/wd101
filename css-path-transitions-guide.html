PASSO 01

Quebrar a Caixa Retangular com clip-path: polygon()

POLYGON CLIPPING MATRIX

O modelo de caixas tradicional (Box Model) restringe todas as secções HTML a retângulos rígidos. Com a propriedade clip-path, criamos um polígono de recorte vetorial acelerado diretamente na GPU, permitindo que a base da secção se incline em diagonais agressivas ou desça em ondas suaves.

TESTE EM TEMPO REAL:
SECÇÃO 01 • SUB-BASS TRENCH 
/* PASSO 1: Recorte poligonal com transição fluida na GPU */
.festival-section {
  /* Define os 4 cantos do polígono (Topo-Esq, Topo-Dir, Base-Dir, Base-Esq) */
  clip-path: polygon(0% 0%, 100% 0%, 100% 85%, 0% 100%);
  
  /* Anima a transição da forma quando a classe ou estado muda */
  transition: clip-path 0.65s cubic-bezier(0.34, 1.56, 0.64, 1);
  
  /* Promove o elemento a uma camada de composição dedicada na GPU */
  will-change: clip-path;
}
PASSO 02

A Regra de Invariância de Vértices: Paridade Estrita (N = 8)

VERTEX PARITY RULE: N=8

Porque é que algumas transições de clip-path dão um salto seco em vez de animar?
O motor do browser (Chromium Blink, Gecko ou WebKit) exige que o polígono de partida e o polígono de chegada contenham rigorosamente o mesmo número de pontos de coordenadas (X, Y). Se o estado A tiver 8 vértices e o estado B tiver 4, o motor aborta a interpolação matemática e efetua um corte instantâneo e feio a meio da transição.

FORMA DO POLÍGONO (N = 8 PONTOS FIXOS):
P0 P1 P2 P3 P4 P5 P6 P7
💡 O Segredo dos Vértices Colineares:
Repare como no formato Angle Slash os pontos intermédios (P3 a P6) não são apagados: são posicionados exatamente ao longo da mesma linha reta oblíqua y = 0.35x + 62%! Visualmente parece uma reta perfeita, mas matematicamente os 8 vértices continuam vivos, garantindo 60fps de interpolação fluida! 
/* PASSO 2: Polígonos invariantes com exatamente 8 vértices cada */
/* Estado 1: Onda Sinusoidal Acústica */
--polygon-sine: polygon(0% 0%, 100% 0%, 100% 80%, 75% 95%, 50% 80%, 25% 65%, 10% 75%, 0% 80%);

/* Estado 2: Corte Angular (P3..P6 colineares na mesma reta) */
--polygon-angle: polygon(0% 0%, 100% 0%, 100% 97%, 75% 88%, 50% 79%, 25% 70%, 10% 65%, 0% 62%);
PASSO 03

Morfismo Declarativo de SVG <path> com d: path(...)

CUBIC BEZIER SVG MORPH

Enquanto o clip-path: polygon() une pontos por segmentos retos, o SVG 2 permite animar o atributo d diretamente nas folhas de estilo CSS. Isto desbloqueia Curvas de Bézier Cúbicas (comando C) com tangentes suaves e curvatura orgânica de som.

TRANSIÇÃO DA CURVA BÉZIER: 
/* PASSO 3: Morfismo de Bézier direto no CSS (sem bibliotecas JavaScript externas) */
.svg-divider path {
  /* Comandos SVG: M = Move, L = Line, C = Cubic Bézier (x1 y1, x2 y2, x y) */
  d: path("M 0,0 L 1000,0 L 1000,50 C 750,110 500,10 250,70 C 120,100 50,30 0,50 Z");
  transition: d 0.85s cubic-bezier(0.34, 1.56, 0.64, 1);
}

/* Ao comutar para corte reto, os pontos de controlo Bézier alinham-se na diagonal */
:root:has(#shape-angle:checked) .svg-divider path {
  d: path("M 0,0 L 1000,0 L 1000,110 C 750,90 500,70 250,50 C 120,38 50,32 0,25 Z");
}
PASSO 04

CSS Motion Path: Navegar a Crista com Baquetas DRUMTIKS

W3C MOTION PATH SPEC

Como fazer com que um elemento gráfico (ex: o logótipo de baquetas do festival) viaje ao longo da curva exata do separador? A especificação W3C Motion Path utiliza: offset-path: path(...) para a trajetória, offset-distance para o avanço (0% a 100%) e offset-rotate: auto para rodar o elemento tangencialmente à inclinação da crista!

CONTROLO MANUAL DE TRAJETÓRIA (OFFSET-DISTANCE): 25% 
/* PASSO 4: Elemento móvel alinhado tangencialmente à curva */
.drumstick-traveler {
  /* 1. Atribui a curva Bézier de viagem */
  offset-path: path("M 40,75 C 280,140 520,10 760,110 C 880,140 940,50 980,75");
  
  /* 2. Posição no percurso (0% = início, 100% = fim) */
  offset-distance: var(--progress, 0%);
  
  /* 3. auto = calcula o ângulo da derivada da curva instantaneamente! */
  offset-rotate: auto 20deg;
  
  /* 4. Fixa o pivô de rotação no centro exato da baqueta */
  offset-anchor: 50% 50%;
}
PASSO 05

Encaixe de Secções sem Falhas (Negative Margin Interlocking)

OVERLAP ANCHORING SPEC

Quando uma secção é recortada na base, a secção seguinte fica separada por um vazio. Para criar um encaixe perfeito como telhas sobrepostas, a segunda secção puxa-se para cima com margem negativa proporcional à altura do recorte e compensa o conteúdo com padding-top interno. 

/* PASSO 5: Encaixe perfeito entre duas secções de palcos diferentes */
:root {
  --path-height: clamp(80px, 12vw, 160px);
}

.section-1-douro {
  padding-bottom: calc(4rem + var(--path-height));
  clip-path: var(--active-polygon);
}

.section-2-vaults {
  /* Puxa a Secção 2 exatamente a altura do corte para cobrir a junta */
  margin-top: calc(-1 * var(--path-height));
  
  /* Compensa para que o texto não colida com a crista da secção anterior */
  padding-top: calc(4rem + var(--path-height));
}
PASSO 06

Acessibilidade Vestibular: WCAG 2.2 & Reduced Motion

WCAG 2.2 CRITERION 2.3.3

Morfismos bruscos e objetos a correr pelo ecrã podem causar vertigens e náuseas a utilizadores com distúrbios vestibulares. O critério WCAG 2.2 — 2.3.3 obriga a respeitar a preferência de redução de movimento configurada no sistema operativo do utilizador: 

/* PASSO 6: Salvaguarda vestibular obrigatória */
@media (prefers-reduced-motion: reduce) {
  .section-clip-morph,
  .svg-divider path,
  .drumstick-traveler {
    /* Desativa a transição lenta de caminho, substituindo por corte instantâneo */
    transition-duration: 0.01ms !important;
    animation: none !important;
  }

  .drumstick-traveler {
    /* Fixa a baqueta estática a 50% do trajeto no centro estável da secção */
    offset-distance: 50% !important;
  }
}
