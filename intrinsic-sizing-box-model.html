1. Objetivos Pedagógicos, Finalidades de Desenvolvimento & Método de Treino 1. Learning Objectives, Development Purposes & Training Method

No Módulo 2, a transição é decisiva: os alunos passam do fluxo puramente vertical do documento HTML básico (EX1) para a disciplina geométrica e modular do CSS moderno (EX2). O design deixa de ser um decalque estático para se tornar um sistema de restrições elásticas governado pelo conteúdo e pelo dispositivo do utilizador. In Module 2, the pedagogical transition is decisive: students advance from raw vertical HTML normal flow (EX1) to the geometric and modular discipline of modern CSS (EX2). Web design ceases to be a static print trace and becomes a system of elastic constraints governed by content and the user's viewport.

A Mudança de Paradigma: Da Caixa Rígida Impressa ao Meio Líquido da Web The Paradigm Shift: From Rigid Print Boxes to the Liquid Medium of the Web

No papel, o formato é imutável (ex: A4 ou cartaz de 70x100 cm). No navegador web, o designer não controla a resolução, o rácio de ecrã ou a densidade de píxeis do leitor. Impor dimensões extrínsecas (como width: 960px;) é tentar congelar um rio que continua a fluir. O dimensionamento intrínseco ensina o navegador a calcular o melhor tamanho possível respeitando limites humanos de legibilidade.

In print design, geometry is immutable (e.g. A4 sheet or 70x100 cm poster). On the web browser, the designer has zero control over the user's resolution, aspect ratio, or pixel density. Forcing rigid extrinsic dimensions (like width: 960px;) is attempting to freeze a river that keeps flowing. Intrinsic sizing teaches the browser to calculate the optimal geometry while respecting human readability limits.

2. O Modelo Mental: Extrínseco vs. Intrínseco & Propriedades Lógicas 2. Mental Model: Extrinsic vs. Intrinsic & Logical Properties

A distinção mais importante no design web moderno é a diferença entre forçar dimensões de fora para dentro (extrínseco) ou deixar o conteúdo adaptar-se ao seu contexto físico de dentro para fora (intrínseco): The most critical distinction in modern web design is between forcing dimensions from the outside in (extrinsic) versus allowing content to adapt to physical context from the inside out (intrinsic):

❌ Dimensionamento Extrínseco RígidoRigid Extrinsic Sizing

Fixar width: 800px; ou height: 400px;. A caixa é cega ao viewport: num telemóvel com 375px de largura, 425px do conteúdo ficam cortados fora do ecrã, gerando scroll horizontal, frustração e rejeição pelo utilizador. Hardcoding width: 800px; or height: 400px;. The box is oblivious to the viewport: on a 375px phone screen, 425px of content overflows off-screen, creating horizontal scrollbars.

✅ Dimensionamento Intrínseco & AdaptativoIntrinsic & Adaptive Sizing

Declarar limites elásticos (width: 100%; max-width: 72rem; ou min(100%, 72rem)). A caixa ocupa a totalidade do ecrã no telemóvel e trava confortavelmente no monitor grande para manter a legibilidade do texto. Declaring elastic boundaries (width: 100%; max-width: 72rem; or min(100%, 72rem)). The box spans 100% on phones and caps smoothly on desktop to safeguard typographic measure.

🌐 Propriedades Físicas vs. Propriedades Lógicas no CSS ModernoPhysical vs. Logical Properties in Modern CSS

Historicamente, o CSS usava coordenadas físicas (left, right, top, bottom). O CSS moderno adota propriedades lógicas agnósticas ao modo de escrita (da esquerda para a direita, ou vertical): Historically, CSS relied on physical coordinates (left, right, top, bottom). Modern CSS adopts logical properties independent of writing modes:

4. O Motor Matemático do CSS Moderno: min(), max(), clamp(), flex-basis & minmax() 4. The Mathematical Engine of Modern CSS: min(), max(), clamp(), flex-basis & minmax()

Em vez de dezenas de media queries com cortes artificiais de ecrã, o CSS moderno fornece funções e operadores matemáticos nativos que realizam interpolação geométrica contínua e distribuição proporcional: Instead of dozens of media queries with artificial cuts, modern CSS provides native mathematical functions and operators that perform continuous geometric interpolation and proportional distribution:

1. min(valor1, valor2)

Escolhe o menor valor entre as opções. Atua como um teto limitador: ocupa 100% no telemóvel, mas trava em 72rem no monitor desktop. Selects the smallest value. Acts as a maximum ceiling: spans 100% on mobile, but locks at 72rem on desktop viewports. 

.container {
  width: min(100%, 72rem);
  margin-inline: auto;
}
MDN: min() ↗

2. max(valor1, valor2)

Escolhe o maior valor. Atua como um piso de segurança: impede que paddings, alvos de toque ou margens colapsem para zero em ecrãs pequenos. Selects the largest value. Acts as a safety floor: prevents paddings, tap targets, or margins from collapsing to zero on tiny screens. 

.section-padded {
  padding-block: max(1.5rem, 5vw);
}
MDN: max() ↗

3. clamp(min, preferido, max)

Tranca um valor entre piso e teto, crescendo proporcionalmente ao viewport. Essencial para tipografia fluida contínua. Clamps a value between floor and ceiling, scaling smoothly with viewport width. The cornerstone of fluid typography. 

h1.hero-title {
  font-size: clamp(2rem, 1.5rem + 2.5vw, 4rem);
}
MDN: clamp() ↗

4. flex-basis (Flexbox)

Determina o tamanho ideal inicial do item antes da distribuição de espaço restante pelos fatores flex-grow e flex-shrink. Defines the ideal starting dimension of a flex item before remaining space is distributed via flex-grow and flex-shrink. 

.stage-card {
  flex: 1 1 18rem; /* grow shrink basis */
}
MDN: flex-basis ↗

5. minmax(min, max) (CSS Grid)

Função de faixas em CSS Grid. Combinada com repeat(auto-fit, ...), cria grelhas responsivas perfeitas sem uma única media query. CSS Grid track function. Combined with repeat(auto-fit, ...), creates responsive grids with zero media queries. 

.stages-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: var(--space-md);
}
MDN: minmax() ↗

6. @container & cqi (Container Queries)

O expoente máximo do dimensionamento intrínseco. O componente adapta-se à largura do elemento-pai (inline-size), e a unidade cqi (1% da largura do contentor) escala a tipografia internamente. The pinnacle of intrinsic responsiveness. Components adapt to their parent container's width (inline-size), and cqi units scale internal type proportionally. 

.card-slot { container-type: inline-size; }
@container (min-width: 420px) {
  .card { display: flex; font-size: clamp(0.9rem, 2.5cqi, 1.25rem); }
}

5. Decomposição dos Padrões de Geometria do EX2 (Drumtiks '26) 5. Deconstructing EX2 Geometry Patterns (Drumtiks '26)

Como estes conceitos teóricos foram materializados de forma simples e abstrata no mini-site de demonstração do DJ Warp no Drumtiks '26: How these theoretical foundations were implemented simply and cleanly in the official DJ Warp Drumtiks '26 demo:

Padrão A: O Escape Hatch do Hero Full-Bleed (100vw) — Quebrando o Modelo de Caixa Pattern A: The Hero Full-Bleed Escape Hatch (100vw) — Breaking the Box Model

Como fazer com que a fotografia do DJ Warp rasgue a página de ponta a ponta sem partir a árvore semântica do <main> (que está contido a 72rem): How to allow the DJ Warp hero photograph to span edge-to-edge without breaking out of the semantic <main> landmark (constrained to 72rem): 

/* Breaking the Box Model: 100vw Escape Hatch */
.hero-full-bleed {
  width: 100vw;
  position: relative;
  left: 50%;
  right: 50%;
  margin-left: -50vw;
  margin-right: -50vw;
  background: radial-gradient(circle at 50% 30%, #1e1e28 0%, #0a0a0d 80%);
}

Mecânica: width: 100vw atribui à caixa a largura total da janela. left: 50% empurra o seu canto esquerdo para o centro da página, e margin-left: -50vw puxa a caixa de volta exatamente meia janela para a esquerda, centrando-a perfeitamente em relação ao ecrã físico. Mechanics: width: 100vw matches viewport width. left: 50% offsets the left edge to the viewport center, and margin-left: -50vw shifts it back by half the viewport width, centering it relative to the physical screen.

Padrão B: Ancoragem de Badges com Posicionamento Relativo & Absoluto Pattern B: Badge Anchoring with Relative & Absolute Positioning

A etiqueta de data/horário nos cartões de palcos do festival: The date/time badge on the festival stage cards: 

/* 1. O Pai estabelece o Contexto de Posicionamento */
.stage-card {
  position: relative;
  padding: var(--space-lg);
  padding-block-start: var(--space-xl); /* Espaço de respiro para o badge */
}

/* 2. O Filho é fixado com precisão milimétrica */
.stage-card-badge {
  position: absolute;
  top: var(--space-sm);
  right: var(--space-sm);
  background-color: var(--color-brand-primary);
  color: #ffffff;
}

Mecânica: Um elemento com position: absolute procura o primeiro ancestral que não seja static. Ao declarar position: relative no cartão-pai, o badge fixa-se no canto superior direito do cartão e acompanha-o se este se mover. Mechanics: An absolute element climbs the DOM until finding an ancestor with non-static positioning. Setting position: relative on the card anchors the badge strictly to the card's top-right corner.

Padrão C: Rácio de Aspeto 16:9 sem Salto de Layout (Zero CLS) Pattern C: 16:9 Aspect Ratio without Layout Shift (Zero CLS)

Encapsulamento de vídeos e mapas embutidos em iframes: Containing responsive videos and embedded map iframes: 

/* Elimina o arcaico hack de padding-top: 56.25% */
.embed-responsive-16-9 {
  aspect-ratio: 16 / 9;
  width: 100%;
  overflow: hidden;
  border-radius: var(--radius-sm);
}

.embed-responsive-16-9 > iframe {
  width: 100%;
  height: 100%;
  border: 0;
}

Mecânica: aspect-ratio: 16 / 9 força o navegador a reservar a altura proporcional antes mesmo do vídeo começar a descarregar, prevenindo que o texto dê saltos visuais súbitos na página. Mechanics: aspect-ratio: 16 / 9 forces the browser to reserve the exact proportional height before network streaming finishes, preventing sudden visual jumps.

Padrão D: Cabeçalho Sticky & Compensação de Âncora com scroll-margin-top Pattern D: Sticky Header & Anchor Clearance with scroll-margin-top

O menu permanece visível ao rolar a página, e as ligações internas não ficam escondidas por trás do cabeçalho: The header sticks upon scrolling, and internal anchor jumps don't hide headings beneath it: 

/* 1. Fixar o Cabeçalho */
.site-header {
  position: sticky;
  top: 0;
  z-index: 100;
  backdrop-filter: blur(8px);
}

/* 2. Compensar a Rolagem para Named Anchors */
section[id] {
  scroll-margin-top: 5.5rem; /* Altura do header + respiro visual */
}

Padrão E: Efeitos de Filtro CSS em Elementos Multimédia Pattern E: CSS Filter Effects on Media Elements

Tratamento gráfico de logótipos e imagens sem necessidade de editar ficheiros no Photoshop: Graphic treatment of partner logos and artist photos without opening Photoshop: 

.partner-logo {
  filter: grayscale(100%) opacity(0.7);
  transition: filter 0.3s ease, opacity 0.3s ease;
}

.partner-logo:hover,
.partner-logo:focus-visible {
  filter: grayscale(0%) opacity(1);

6. Diagnóstico de Geometria no Inspetor do Navegador (DevTools) 6. Geometry Debugging in Browser DevTools

Nunca adivinhe porque é que uma barra de rolamento horizontal surgiu. Utilize as ferramentas de diagnóstico integradas no browser: Never guess why a horizontal scrollbar appeared. Leverage built-in browser inspection tools:

  • Modo de Dispositivos Móveis (Toggle Device Toolbar): Teste primeiro a 320px (iPhone SE mínimo) e depois a 375px e 414px. Se a página deslizar para o lado, há uma caixa rígida que precisa de correção.Device Mode: Test first at 320px (iPhone SE minimum floor) and then 375px and 414px. If the page drifts sideways, an offending rigid box exists.
  • Diagrama do Modelo de Caixa: No painel Computed / Layout, passe o rato sobre a caixa para ver a marcação de cores: Azul (conteúdo), Verde (padding), Amarelo (border), Laranja (margin).Box Model Diagram: Under the Computed / Layout panel, hover over the diagram to observe color highlighting: Blue (content), Green (padding), Yellow (border), Orange (margin).
  • Deteção de Overflow com a Consola: Se houver overflow invisível, execute na consola JavaScript: document.querySelectorAll('*').forEach(el => el.scrollWidth > document.documentElement.clientWidth && console.log(el)) para listar os elementos culpados.Console Overflow Detection: In case of elusive overflow, run in the JS console: document.querySelectorAll('*').forEach(el => el.scrollWidth > document.documentElement.clientWidth && console.log(el)) to pinpoint the offending nodes.
