1. Enquadramento & Desafio Pedagógico

O Exercício 1 marca a transição da teoria para o desenvolvimento web real. O objetivo é dominar o fluxo normal do documento e o modelo de caixa sem muletas visuais:

Zero Classes Cosméticas

Proibido criar classes do tipo class="titulo" ou class="texto-principal". O estilo é transmitido pela árvore hierárquica (seletores descendentes).

Tolerância Zero a <div>

Não utilize contentores genéricos onde existe um marco semântico nativo (header, nav, main, section, article, aside, footer).

Zero Imagens Externas

O foco é exclusivamente tipográfico: escala modular em rem, entrelinha unitless e caixas elásticas limitadas a 75ch.

  • index.html: Ficheiro de Índice Padrão (DirectoryIndex) ↗ — Nome reservado que a generalidade dos servidores HTTP (Apache, Nginx) procura e serve automaticamente quando um cliente acede a uma pasta (ex: .../ex1/). Reserved filename that HTTP servers (Apache, Nginx) automatically search for and serve when a client requests a folder (e.g., .../ex1/).   • Caminhos Relativos: URLs e Caminhos Relativos ↗ — Um caminho como css/style.css indica ao navegador para procurar a pasta css a partir da localização do ficheiro HTML que o invocou. A relative path like css/style.css instructs the browser to look inside the css folder relative to the location of the referencing HTML file. Never use local hard-drive absolute paths (such as C:\Users\... or /Volumes/...), as they break immediately upon upload to a remote server.

O que são Atributos HTML? What are HTML Attributes?
Os atributos são modificadores colocados no interior da tag de abertura de um elemento na sintaxe nome="valor". Servem para fornecer metadados, configurar comportamentos adicionais ou criar relações externas que a tag por si só não expressa. Attributes are modifiers placed inside an element's opening tag using the name="value" syntax. They supply metadata, configure supplementary behaviors, or create external relationships that the bare tag cannot convey alone.

  • <!DOCTYPE html>: Declaração de Tipo de Documento (Doctype) ↗ — Informa o motor de renderização do navegador de que o documento segue o padrão moderno do W3C / WHATWG HTML5 Living Standard, evitando a ativação do arcaico modo de compatibilidade (*Quirks Mode*). Informs the browser rendering engine that the document complies with the modern W3C / WHATWG HTML5 Living Standard, preventing fallback into archaic Quirks Mode.
  • <html> com atributo lang="pt-PT": Elemento Raiz HTML ↗ e Atributo Global lang ↗ — Define a língua principal do documento. Vital para que sintetizadores de voz para pessoas cegas pronunciem as palavras corretamente e para motores de busca indexarem a página por região geográfica. Specifies the primary language of the document. Essential for screen readers to pronounce words correctly and for search engines to index content geographically.
  • <head>: Contentor de Metadados Head ↗ — Contém todas as instruções técnicas, títulos, ligações a estilos e scripts que não são exibidos diretamente na janela de conteúdo. Contains technical instructions, document titles, linked stylesheets, and scripts that are not directly painted onto the document viewport.
  • <meta> com atributo charset="UTF-8": Elemento Meta ↗ e Atributo charset ↗ — Codificação universal de caracteres Unicode. Garante que acentos portugueses (ç, ã, é, ó), pontuação especial e alfabetos internacionais não aparecem corrompidos como pontos de interrogação ou caracteres ilegíveis. Universal Unicode character encoding. Guarantees accented characters (ç, ã, é, ó), special punctuation, and international scripts do not corrupt into question marks or garbled text.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">: Instrução Meta Viewport ↗ — A regra mais importante do Responsive Web Design:
    • name="viewport": Indica ao browser móvel que esta instrução se destina à janela de visualização do ecrã físico.
    • content: Agrupa os parâmetros de controlo separados por vírgula.
    • width=device-width: Força a largura do viewport a coincidir com os píxeis CSS do ecrã real, impedindo o telemóvel de simular um desktop de 980px em zoom reduzido microscópico.
    • initial-scale=1.0: Define a escala inicial em 100% (proporção 1:1 entre píxeis do dispositivo e píxeis CSS).     The single most critical instruction for Responsive Web Design:
    • name="viewport": Signals mobile browsers that this directive governs physical screen viewport scaling.
    • content: Bundles comma-separated layout parameters.
    • width=device-width: Forces the viewport width to match actual CSS screen pixels, preventing mobile devices from simulating a 980px desktop window in microscopic zoom.
    • initial-scale=1.0: Sets initial zoom to 100% (1:1 ratio between CSS pixels and device pixels).
  • <title>: Título do Documento ↗ — O texto único e descritivo que surge no separador do navegador, no histórico e nos resultados da Google. Unique and descriptive title appearing in browser tabs, bookmarks, and search engine SERPs.
  • <meta name="description" content="...">: Metadados de Descrição ↗ — Resumo textual do conteúdo utilizado por motores de busca e cartões de pré-visualização. Textual summary of document contents utilized by search indexers and social link preview snippets.
  • <link rel="stylesheet" href="css/style.css">: Elemento Link ↗:
    • rel="stylesheet": Atributo rel (Relationship) ↗ — Estabelece a relação semântica do recurso externo. Informa o motor de renderização de que o ficheiro apontado é uma folha de estilos CSS a aplicar. Defines the semantic relationship to the external asset. Informs the rendering engine that the resource is an active CSS stylesheet.
    • href="css/style.css": Atributo href (Hypertext Reference) ↗ — O endereço relativo onde se encontra fisicamente o ficheiro CSS a descarregar. The relative URL where the external CSS file is physically located.

O Atributo Global id & Named Anchors: Global id Attribute & Named Anchors:
O atributo id (MDN id ↗) atribui um identificador único a um elemento no documento. Regra de ouro: Nunca podem existir dois elementos com o mesmo valor de ID na mesma página! Serve para dois propósitos capitais:
1. Named Anchors (Âncoras Internas): Uma ligação como <a href="#biografia"> instrui o navegador a procurar o elemento com id="biografia" e a deslocar a janela imediatamente para essa posição.
2. Alvo de Seleção CSS e JavaScript: Permite estilização e seleção específica através do seletor #id. The id attribute (MDN id ↗) assigns an identifier unique across the entire document. Golden Rule: No two elements can ever share the same ID value! It serves two crucial functions:
1. Named Anchors (In-Page Navigation): A link like <a href="#biografia"> instructs the browser to locate the element with id="biografia" and scroll directly to it.
2. Target for CSS & JavaScript: Enables hyper-specific styling and element manipulation via #id.

O Atributo aria-label & Acessibilidade (a11y): The aria-label Attribute & Accessibility (a11y):
O atributo aria-label (MDN aria-label ↗) fornece uma legenda descritiva acessível a tecnologias de apoio (como leitores de ecrã para cegos). Quando uma página possui mais do que um elemento <nav> (ex: navegação principal vs. navegação de rodapé), o aria-label é obrigatório para diferenciar o contexto semântico de cada menu. The aria-label attribute (MDN aria-label ↗) gives assistive technologies (such as screen readers) a clear, descriptive label. Whenever a page includes multiple <nav> landmarks, aria-label is required to differentiate their purpose.

As 3 Tipologias Obrigatórias de Hiperligações (<a>): The 3 Mandatory Hyperlink Typologies (<a>):
1. Âncora Interna (Named Anchor): <a href="#biografia"> — Navegação instantânea dentro do mesmo ficheiro sem novo pedido HTTP.
2. Ligação Externa Segura: <a href="https://..." target="_blank" rel="noopener noreferrer"> — Abre num novo separador. O atributo rel="noopener noreferrer" ↗ é crucial para evitar ataques de *tabnabbing* (impede que o site de destino controle o objeto window.opener da sua página).
3. Ligação de Correio Eletrónico: <a href="mailto:djwarp@drumtiks.up.pt"> — Dispara o cliente de correio nativo do sistema operativo configurado pelo utilizador. 1. Internal Named Anchor: <a href="#biografia"> — Instant in-page jump without triggering a new HTTP network request.
2. Hardened External Link: <a href="https://..." target="_blank" rel="noopener noreferrer"> — Opens in a new tab. The rel="noopener noreferrer" ↗ attribute prevents *tabnabbing* exploits by severing access to window.opener.
3. Direct Email Link: <a href="mailto:djwarp@drumtiks.up.pt"> — Triggers the user operating system default email application.

O Seletor Universal (*): The Universal Selector (*):
O seletor * (MDN Universal Selector ↗) seleciona todos os elementos do DOM. Tem uma especificidade nula (0,0,0), o que o torna a fundação ideal para resets globais. A combinação com box-sizing: border-box altera o cálculo geométrico: o padding e o border passam a ser subtraídos do tamanho total da caixa, eliminando scrolls horizontais inesperados. The * selector (MDN Universal Selector ↗) matches every single DOM element. It has zero specificity (0,0,0), making it the perfect foundation for global resets. Combined with box-sizing: border-box, padding and border are absorbed inside the element's specified width, eliminating unintended horizontal scrollbars.

A Notação Shorthand do Modelo de Caixa (Sistema Horário TRBL): Box Model Shorthand Notation (TRBL Clock System):
Propriedades como margin e padding podem receber entre 1 a 4 valores seguindo o sentido dos ponteiros do relógio: Properties like margin and padding accept 1 to 4 values following clockwise rotation:

  • 4 Valores: margin: TOP RIGHT BOTTOM LEFT;
    Exemplo: margin: 0 auto 3rem auto; → Topo: 0, Direita: auto, Fundo: 3rem, Esquerda: auto. Example: margin: 0 auto 3rem auto; → Top: 0, Right: auto, Bottom: 3rem, Left: auto.
  • 3 Valores: margin: TOP (RIGHT & LEFT) BOTTOM;
    Exemplo: padding: 1rem 2rem 3rem; → Topo: 1rem, Laterais: 2rem, Fundo: 3rem. Example: padding: 1rem 2rem 3rem; → Top: 1rem, Sides: 2rem, Bottom: 3rem.
  • 2 Valores: margin: (TOP & BOTTOM) (RIGHT & LEFT);
    Exemplo: padding: 2rem 1.25rem; → Vertical: 2rem, Horizontal: 1.25rem. Example: padding: 2rem 1.25rem; → Vertical: 2rem, Horizontal: 1.25rem.
  • 1 Valor: margin: ALL-4-SIDES;
    Exemplo: margin: 0; → Aplica 0 nos quatro lados da caixa. Example: margin: 0; → Applies 0 to all 4 sides of the box.

Como Funcionam as Cores no CSS: How Colors Work in CSS:

Seletores Descendentes vs. Classes Cosméticas: Descendant Selectors vs. Cosmetic Classes:
O seletor header nav ul li a utiliza o combinador descendente (espaço). Indica ao navegador para aplicar as regras a qualquer elemento <a> que se encontre dentro de um <li>, dentro de um <ul>, dentro de um <nav>, dentro do <header>. Isto elimina a necessidade de poluir o HTML com class="link-navegacao", mantendo o markup limpo, semântico e focado exclusivamente no conteúdo. The selector header nav ul li a uses the descendant combinator (space). It styles any <a> nested inside <li>, inside <ul>, inside <nav>, inside <header>. This completely eliminates cluttering the HTML with arbitrary classes like class="nav-link", preserving a lean, semantic DOM tree.
