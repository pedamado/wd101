Anatomia & Comentários Pedagógicos

1. A Matemática do Círculo com 4 Curvas de Bézier Cúbicas

No SVG e no CSS path(), um círculo não possui uma primitiva dedicada; é desenhado com 4 segmentos cúbicos (comando C). A constante ótima de aproximação é κ = 4(√2 - 1)/3 ≈ 0.55228475. Num círculo de raio r = 100 centrado em (100,100): 

/* Ponto inicial no topo (100, 0) */
M 100,0 

/* Quadrante 1 (Topo -> Direita) */
C 155.2,0 200,44.8 200,100 

/* Quadrante 2 (Direita -> Fundo) */
C 200,155.2 155.2,200 100,200 

/* Quadrante 3 (Fundo -> Esquerda) */
C 44.8,200 0,155.2 0,100 

/* Quadrante 4 (Esquerda -> Topo) + Fecho */
C 0,44.8 44.8,0 100,0 Z

2. A Função de Temporização Elástica linear(...)

Historicamente, as funções cubic-bezier(x1, y1, x2, y2) no CSS estavam limitadas a curvas cúbicas simples onde os pontos de controlo não podiam modelar oscilações múltiplas. A nova função linear(...) da W3C recebe uma série de coordenadas percentuais discretas aproximadas de equações de amortecimento físico: 

transition: clip-path 0.8s linear(
  0,
  0.053  0.5%,  /* Início do impulso */
  0.238  1.1%,
  1.460  3.6%,  /* Primeiro overshoot (> 1.0) */
  1.673  4.8%,  /* PICO MÁXIMO DA MOLA (+67.3% além da meta!) */
  0.547  9.6%,  /* Recuo abaixo do valor final (-45.3%) */
  1.305 14.4%,  /* Segundo ressalto atenuado (+30.5%) */
  0.795 19.1%,  /* Segundo recuo atenuado (-20.5%) */
  1.138 23.9%,  /* Terceira oscilação residual (+13.8%) */
  0.907 28.7%,  /* Quarta oscilação quase impercetível (-9.3%) */
  1.063 33.5%,
  0.958 38.3%,
  1.028 43.1%,
  1             /* Estabilização perfeita a 100% aos 0.8s */
);
