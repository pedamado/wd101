PALCO 01 • RIO DOURO FRONT

CSS Path (Shape) Transition Demo

Demonstração curricular de morfismo de secções por caminhos CSS para o Festival DRUMTIKS '26. Observe como o recorte inferior desta secção e a caixa interativa #shape abaixo adaptam a sua geometria em tempo real, com interpolação de vértices de 60/120 fps acelerada na GPU.

CSS ELEMENT INTERACTIVE SANDBOX

Caixa de Teste: <div id="shape">

Este elemento HTML utiliza a mesma propriedade clip-path: var(--active-polygon) que o separador da secção principal. Passe o rato por cima ou alterne os botões da consola superior para testemunhar a transição fluida entre geometrias!

DRUMTIKS BPM SYNCED
〰️

Invariância de Vértices (N = 8)

Para que a transição CSS de um polígono não salte bruscamente, o estado inicial e o estado final têm de conter exatamente a mesma quantidade de coordenadas (X, Y).

🥢

Baquetas em CSS Motion Path

A especificação offset-path: path(...) guia o par de baquetas luminosas ao longo da crista da secção, orientando o seu ângulo de percussão com offset-rotate: auto 20deg.

⚡

Física de Ressalto (Spring Easing)

A curva cubic-bezier(0.34, 1.56, 0.64, 1) ultrapassa a posição final antes de estabilizar, simulando a elasticidade física e vibração da membrana de um tambor percutido.

PALCO 02 • GRANITE VAULTS

Granite Vaults & Interlocking Sections

Os arcos de cantaria da Alfândega do Porto exigem uma continuidade volumétrica sem falhas de píxeis. Demonstramos aqui como articular blocos de cores diferentes utilizando margens negativas proporcionais margin-top: calc(-1 * var(--path-divider-height)) compensadas com padding interno.

🏛️

Encaixe Sub-Pixel Perfeito

Sem espaços em branco entre secções: o separador da secção anterior cobre exatamente a linha de junção, criando uma ilusão de recorte físico contínuo.

🎛️

Colinearidade de Vértices

No formato Angle Slash, os pontos da onda alinham-se na reta y = 0.35x + 62%. Visualmente parece uma diagonal reta, mas matematicamente os 8 vértices persistem para a transição!

📐

Morfismo de Atributo SVG `d`

O CSS moderno permite animar o caminho SVG d: path(...) diretamente na folha de estilos, interpolando curvas de Bézier cúbicas suaves (comando C).

PALCO 03 • TURNTABLISM OCTAGON

Radial Vinyl Arcs & Scratch Physics

O formato de caminho Vinyl Arc simula a borda exterior de um disco de vinil a 33⅓ RPM. Os pontos centrais da curva convergem para criar um arco circular parabólico contínuo.

CSS Path Engineering & Live Matrix HUD

Analise em detalhe a regra CSS que comanda as transições em curso. Todos os valores são dinamicamente alimentados pelas variáveis comutadas no topo do documento.

INSPETOR DE REGRAS CSS VIVAS (LIVE CASCADE MATRIX)
Especificidade: (0, 2, 0) via :root:has() 
/* ==========================================================================
   REGRA CSS ATIVA PARA O SEPARADOR DE SECÇÃO E #shape (TP09)
   Interpolação de coordenadas com paridade de vértices garantida (N = 8)
   ========================================================================== */
.section-clip-morph,
#shape {
  clip-path: var(--active-polygon);
  transition: clip-path var(--transition-duration-morph) var(--active-ease);
  will-change: clip-path;
}

.drumstick-traveler {
  offset-path: var(--active-motion-path);
  offset-rotate: auto 20deg;
  offset-anchor: 50% 50%;
  transition: offset-path var(--transition-duration-morph) var(--active-ease);
}
