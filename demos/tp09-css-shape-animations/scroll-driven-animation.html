Scroll-Driven Animations

Demonstrador curricular que elimina a dependência de listeners JavaScript de scroll (window.onscroll). O próprio motor gráfico (GPU compositor) mapeia a rolagem da janela para os fotogramas da animação CSS, atingindo 120 fps constantes.

Dissecação do Código da Aula

1. animation-timeline: scroll()

nav div {
  position: absolute;
  top: 0;
  left: 0;
  width: 100px;
  height: 100px;
  background-color: var(--color-primary);
  border-radius: 25%;

  transform-origin: 30% 0%;
  animation-name: expandAnimation;
  animation-duration: 1ms; /* Requisito Firefox */
  animation-direction: alternate;
  animation-timeline: scroll();
}

@keyframes expandAnimation {
  from { transform: scale(1); }
  to   { transform: scale(4); left: 0; }
}

2. animation-timeline: view()

article {
  position: relative;
  display: block;
  width: 200px;
  height: 100px;
  background-color: aquamarine;

  transform-origin: center left;
  animation-timeline: view(block 30% 30%);
  animation-name: expandWide;
  animation-timing-function: linear;
  animation-fill-mode: both;
}

@keyframes expandWide {
  from { transform: scaleX(1); }
  to   { transform: scaleX(2); }
}
