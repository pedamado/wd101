PROJECT CREDITS & PEDAGOGICAL ARCHITECTURE

This interactive festival web portal was conceptualized, designed, and engineered as an advanced pedagogical demonstration of modern Responsive Web Design (RWD), progressive enhancement, and zero-JavaScript CSS state architecture for the Web Design curriculum (WD101) at FBAUP.

COURSE LEARNING OUTCOMES

CORE CURRICULAR COMPETENCIES DEMONSTRATED

  • 1. Strict Semantic HTML5 Landmark Architecture: Full utilization of <header>, <nav>, <main>, <article>, <section>, <aside>, <figure>, <figcaption>, and <footer> ensuring screen reader accessibility and structural clarity.
  • 2. Mobile-First Progressive Enhancement: Default styling optimized for mobile viewports (<600px) with non-destructive expansion via @media (min-width: 600px) and @media (min-width: 960px) into a sticky two-column desktop canvas.
  • 3. Fluid Typographic Math (clamp()): Eliminating static pixel typography in favor of viewport-responsive formulas such as clamp(1.75rem, 4vw, 3.25rem) for impactful, zero-overflow headline scaling.
  • 4. Pure CSS Reactive Engine (No JavaScript): State simulation powered by the modern :root:has(#pass-radio:checked) parent selector, CSS generated content ::after counters, and accessible modal popups via :target.
  • 5. Multi-Breakpoint Art-Direction & Image Optimization: Utilizing <picture> and srcset to deliver 16:9 widescreen, 1:1 square, and 9:16 vertical image crops in both ultra-efficient modern WebP and universal JPEG formats.
  • 6. Self-Hosted Variable Webfonts (Vendorization): Complete local hosting of WOFF2 variable fonts (Inter, Martian Mono, Syne) eliminating third-party tracking and external CDN dependencies.
  • 7. Pure CSS Scroll-Driven Animations: Real-time reading progress indicators and visual reveal effects powered by modern animation-timeline: scroll(root).
  • 8. Native CSS Carousel Snap & Details Transitions: Horizontal gallery snap pagination and smoothly folding accordion components without a single line of script.

TYPOGRAPHY FAMILIES

  • Display Headings: Syne (Variable 400..800, Bold Display Display)
  • Data & Badges: Martian Mono (Variable 100..800, Monospace Precision)
  • Body & UI Controls: Inter (Variable 100..900, High Legibility Sans)

RESPONSIVE BREAKPOINTS

  • Mobile (Default): < 600px (1-column fluid stack)
  • Tablet: @media (min-width: 600px) (Expanded padding, 2-col gallery)
  • Desktop: @media (min-width: 960px) (2-column sticky layout)
  • Widescreen: @media (min-width: 1280px) (1240px centered container)
