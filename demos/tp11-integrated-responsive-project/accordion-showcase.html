ENGINEERING NOTES // FBAUP WD101

Accordion Architectural Breakdown

How modern HTML living standards and advanced CSS selectors eliminate the need for heavy JavaScript libraries.

🏷️ Exclusive Accordion via `name`

In the HTML Living Standard, assigning a matching name="group-name" attribute across multiple <details> elements automatically establishes an exclusive disclosure set. The browser natively manages single-item expansion without JavaScript event listeners.

⚡ Preset Open State

Adding the boolean attribute open directly on any <details> tag ensures the specified pane is pre-expanded immediately upon page delivery, guaranteeing zero layout shift and instant indexing.

🔄 Pure CSS Changing Labels

Dual text elements (.label-closed and .label-opened) are conditionally toggled via details[open] .label-closed { display:none }. This allows descriptive labels ("Inspect Frequencies" vs "Hide Frequencies") with zero DOM manipulation.

🎨 Alternating Contextual SVG Icons

Using CSS transitions on .icon-state--closed and .icon-state--opened, icons seamlessly rotate, scale, and cross-fade. Contextual animations (spinning vinyl, soundwave equalizers) activate automatically under details[open].

🔗 Remote & Cross-Pane Deep Linking

By coupling anchor elements (<a href="#pane-id">) with the CSS :target pseudo-class and native fragment navigation, specific panes can be activated from outside toolbars or from cross-references inside other panes.

📐 Smooth Intrinsic Animations

Using interpolate-size: allow-keywords on :root paired with ::details-content allows modern browsers to transition smoothly between block-size: 0 and auto, with a grid-template-rows: 0fr → 1fr fallback for legacy browsers.
