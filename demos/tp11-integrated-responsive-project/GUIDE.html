This document provides the exhaustive architectural breakdown and pedagogical rationale for transforming the basic two-column festival website into an industry-grade, zero-JavaScript responsive masterclass combining 2D CSS Grid, 1D alternating Flexbox, 3D CSS Transitions, and native Scroll-Driven Animations.

2. The 8 Transformation Steps

Step 1: Mobile-First Progressive Escalation

Instead of designing for desktop and trying to shrink down with max-width, write the default stylesheet for small portrait mobile screens first. Add min-width: 540px, min-width: 768px, and min-width: 1120px media queries to progressively enhance the experience as screen real estate expands.

Step 2: 2D Grid with Named Template Areas

Assign semantic names to page regions via grid-template-areas. On desktop screens (≥ 1120px), pin the DJ Warp hero showcase to the left column with position: sticky; top: var(--space-xl); so it stays in view while the user scrolls through the festival program.

Step 3: Dense Masonry Gallery with Editorial Voids

Combine grid-template-columns: repeat(4, 1fr) and grid-auto-flow: dense. Inject .gallery-tile--void elements containing typographic monograms ("1869", "808") to give breathing room to the photographs, inspired by Swiss modernist posters.

Step 4: Alternating 1D Flexbox Alignment

For schedule items, ticket cards, and navigation links: use flex-direction: column on mobile devices to provide generous touch targets (≥ 44px), and switch to flex-direction: row; flex-wrap: wrap; justify-content: space-between; on larger viewports.

Step 5: Zero-JS Theming with light-dark() and :has()

Configure all color tokens with light-dark(lightColor, darkColor) in :root. Bind hidden radio buttons to :root:has(#theme-light:checked) { color-scheme: light; } to enable users to toggle themes without JavaScript.

Step 6: 3D Vinyl Crate Fan-out

Establish a 3D perspective context with perspective: 1000px. Rotate sleeves along their base using transform-origin: bottom center, and apply cubic-bezier(0.34, 1.56, 0.64, 1) for a physical spring bounce when hovered or focused.

Step 7: Pure CSS Scroll-Driven Animations

Use animation-timeline: scroll(root) to link the top progress bar to the vertical scroll of the document. Use animation-timeline: view() with animation-range: entry 10% cover 30% to reveal content cards as they enter the screen.

Step 8: Pure CSS X-Ray Matrix Overlay

Leverage :root:has(#xray-toggle:checked) to render cyan dashed outlines on CSS Grid containers and magenta solid borders on Flexbox containers, providing an interactive debugging tool for students.
