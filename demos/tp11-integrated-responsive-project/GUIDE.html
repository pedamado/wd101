2. Os 8 Passos da Transformação Arquitetural 2. The 8 Architectural Transformation Steps

Cada passo reflete uma decisão estrutural implementada no código oficial do Capstone Final, acompanhada pela regra de boas práticas MDN e snippets CSS prontos para estudo: Each step reflects a concrete architectural decision implemented in the official Final Capstone codebase, paired with MDN best practices and ready-to-study CSS snippets:

PASSO 1 Escalação Mobile-First em 4 Patamares Progressivos Mobile-First Escalation Across 4 Progressive Tiers

Abandonar a lógica de degradação graciosa com max-width. Todo o layout inicial é desenhado para o ecrã vertical mais restrito (<600px com largura mínima bloqueada em 320px). Apenas quando o espaço físico existe é que introduzimos min-width: Banish graceful degradation with max-width. The entire baseline layout is built for the most constrained mobile screen (<600px with min-width locked at 320px). Only when viewport width permits do we escalate with min-width:

Especificação Técnica & Breakpoints Oficiais 
/* 1. Mobile Portrait Default (Base - Sem Media Query) */
:root {
  --content-min-width: 320px;
}
body {
  min-width: var(--content-min-width);
  overflow-x: hidden;
}
.portal-container {
  width: 100%;
  display: flex;
  flex-direction: column;
  gap: var(--space-6);
}

/* 2. Mobile Landscape & Phablets (>= 600px) */
@media (min-width: 600px) {
  .ticket-options-grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: var(--space-3);
  }
}

/* 3. Tablet & Small Laptop (>= 768px) */
@media (min-width: 768px) {
  .pricing-simulator-box {
    display: grid;
    grid-template-columns: 1.2fr 0.8fr;
    gap: var(--space-6);
  }
  .festival-gallery-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* 4. Desktop Widescreen (>= 1200px) */
@media (min-width: 1200px) {
  .portal-macro-grid {
    display: grid;
    grid-template-columns: minmax(380px, 460px) 1fr;
    grid-template-areas:
      "stage-headliner stage-schedule"
      "stage-headliner stage-gallery"
      "stage-headliner stage-simulator"
      "stage-headliner stage-faq";
    gap: var(--space-8);
  }
}
  • min-width: 320px: Garante que mesmo em smartphones ultra-compactos não há quebras destrutivas de layout.
  • overflow-x: hidden no contentor pai: Evita a barra de deslocamento lateral em ecrãs táteis, mantendo alvos de toque ≥ 44px conformes com as WCAG 2.2.

PASSO 4 Micro-Layout 1D Flexbox Alternante & Acessibilidade Tátil Alternating 1D Flexbox Micro-Layout & Touch Accessibility

A Regra de Ouro do Layout Moderno dita: Grid 2D para a estrutura macro exterior, Flexbox 1D para alinhamentos micro interiores. A direção flexível alterna conforme a largura para garantir ergonomia nos dedos (≥ 44px): The Golden Rule of Modern Layout: 2D Grid for macro structural skeleton, 1D Flexbox for internal micro-alignments. Flex direction alternates based on viewport size to preserve touch ergonomics (≥ 44px):

Fluxo Vertical nos Telemóveis vs. Horizontal Fluido no Desktop 
/* Mobile Base: Coluna Vertical Esticada */
.schedule-item-bar {
  display: flex;
  flex-direction: column;
  align-items: stretch;
  gap: var(--space-2);
  min-height: 48px; /* Alvo táctil WCAG 2.2 */
}

/* Desktop ≥ 768px: Linha Horizontal Distribuída */
@media (min-width: 768px) {
  .schedule-item-bar {

    align-items: center;

    flex-wrap: wrap;
  }

  • MDN Web Docs: CSS flex-direction ↗: Garante que os botões de seleção de passes e horários nunca sofram aperto de texto nem scroll horizontal inadvertido.

PASSO 5 Motor de Theming Dinâmico Zero-JS com light-dark() & Seletor :has() Zero-JS Dynamic Theming Engine with light-dark() & :has() Selector

Elimina complexos scripts de troca de classes no <body>. Os tokens de cor utilizam a função CSS nativa light-dark(corClara, corEscura), orquestrada por radio buttons associados ao seletor relacional :has(): Eliminates bloated JavaScript class-toggling scripts on <body>. Color tokens leverage the native light-dark(lightColor, darkColor) CSS function, orchestrated via radio buttons linked through the :has() relational selector:

Tokens Duais & Máquina de Estados de Tema 
:root {
  color-scheme: light dark;
  --color-bg-base: light-dark(#f8fafc, #090a0f);
  --color-bg-surface: light-dark(#ffffff, #13151f);
  --color-text-main: light-dark(#0f172a, #f8fafc);
  --color-border-subtle: light-dark(#e2e8f0, #26293b);
}

/* Modos Forçados pelo Utilizador sem JavaScript */
:root:has(#theme-light:checked) {
  color-scheme: light;
}
:root:has(#theme-dark:checked) {
  color-scheme: dark;
}
  • MDN Web Docs: light-dark() CSS Color Function ↗: Resolve as cores automaticamente com base na preferência do sistema operativo (prefers-color-scheme) ou na propriedade declarada color-scheme.

PASSO 6 Caixa 3D de Vinil Interativa com Molas Elásticas cubic-bezier() Interactive 3D Vinyl Crate Showcase with Spring Physics cubic-bezier()

No Capstone Integrado, o gira-discos do artista é acompanhado por uma caixa física de discos em perspetiva tridimensional (perspective: 1000px). Ao passar o cursor ou o foco por teclado, as capas abrem em leque com ressalto elástico e o vinil preto desliza para fora da capa: In the Integrated Capstone, the DJ WARP turntable stage features a physical 3D vinyl crate (perspective: 1000px). On hover or keyboard focus, album sleeves fan out with physical spring easing while the black vinyl disc slides out:

Perspetiva 3D, Origem de Transformação & Física de Molas 
.vinyl-crate-scene {
  perspective: 1000px;
  perspective-origin: 50% 100%;
}
.vinyl-sleeve {
  transform-origin: bottom center;
  transform-style: preserve-3d;
  transition: transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);
}

/* Abertura em Leque no Hover/Focus */
.vinyl-crate:hover .vinyl-sleeve:nth-child(1) {
  transform: rotate(-12deg) translateY(-8px);
}
.vinyl-crate:hover .vinyl-sleeve:nth-child(2) {
  transform: rotate(0deg) translateY(-14px);
}
.vinyl-crate:hover .vinyl-sleeve:nth-child(3) {
  transform: rotate(12deg) translateY(-8px);
}

/* Extração do Disco de Vinil da Capa */
.vinyl-sleeve:hover .vinyl-disc {
  transform: translateX(65%) rotate(180deg);
  opacity: 1;

PASSO 7 Animações Nativas Orientadas ao Scroll: scroll(root) & view() Native Scroll-Driven Animations: scroll(root) & view()

Sem qualquer biblioteca externa ou window.addEventListener('scroll') que bloqueia o thread principal da renderização, o Capstone Integrado utiliza a especificação moderna de Scroll-Driven Animations: Without any external JavaScript libraries or heavy scroll event listeners that choke the main thread, the Integrated Capstone applies the modern CSS Scroll-Driven Animations specification:

Barra de Progresso do Viewport & Revelação de Cartões 
/* 1. Barra de Progresso no Topo do Ecrã */
.viewport-progress-bar {
  position: fixed;
  top: 0;
  left: 0;
  height: 4px;
  background: var(--color-accent-cyan);
  width: 100%;
  transform-origin: left center;
  animation: grow-progress auto linear;
  animation-timeline: scroll(root);
  z-index: 1000;
}
@keyframes grow-progress {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

/* 2. Revelação Gradual dos Cartões ao Entrarem no Ecrã */
.reveal-on-scroll {
  animation: reveal-up auto cubic-bezier(0.16, 1, 0.3, 1) both;
  animation-timeline: view();
  animation-range: entry 10% cover 30%;
}
@keyframes reveal-up {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0); }
}
  • MDN Web Docs: Scroll-driven animations ↗: Executadas diretamente no thread do compositor gráfico do navegador a 60/120fps fluidos.

Deteção de Elementos por :has() & Visualização Diagnóstica

  /* Grelhas CSS Grid 2D assinaladas a tracejado Ciano */
  [class*="grid"], .portal-macro-grid, .festival-gallery-grid {
    outline: 2px dashed var(--color-accent-cyan) !important;
    outline-offset: -2px;
  }
  
  /* Contentores 1D Flexbox assinalados com linha contínua Magenta */
  [class*="flex"], .schedule-item-bar, .site-nav ul {
    outline: 2px solid var(--color-accent-magenta) !important;
    outline-offset: -2px;
  }

  /* Vazios Editoriais marcados com badge Dourado */
  .gallery-tile--void::after {
    content: "EDITORIAL VOID (2D GRID)";
    font-family: var(--font-mono);
    font-size: 10px;

    color: #000;
    padding: 2px 6px;
    position: absolute;
    top: 4px;
    left: 4px;
  }
}
  • MDN Web Docs: The :has() relational pseudo-class ↗: Permite que um input no cabeçalho altere o aspeto de toda a árvore de renderização sem uma única linha de JavaScript.
