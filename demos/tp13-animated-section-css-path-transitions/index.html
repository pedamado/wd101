PALCO 01 • RIO DOURO FRONT

Sub-Bass Trench & Acoustic Morphing

Localizado no cais da Alfândega do Porto, este palco explora frequências sub-graves entre os 20 Hz e os 60 Hz. A linha divisória inferior desta secção é calculada através de morfismo vetorial de caminhos CSS, respondendo em tempo real às opções selecionadas na consola de estúdio.

CSS CLIP-PATH PLAYGROUND

Caixa de Teste: <div id="shape">

Este elemento HTML utiliza a propriedade clip-path com a regra estrita de 8 vértices invariantes. Observe a onda a oscilar continuamente ao ritmo do festival (140 BPM) ou comute os botões da consola superior para testemunhar a transição fluida entre geometrias!

DRUMTIKS 140 BPM SYNC
〰️

Morfismo de Vértices Invariantes

Cada polígono é construído com exatamente 8 vértices de coordenadas. A transição transition: clip-path 0.85s var(--active-ease) garante interpolação fluida na GPU a 60/120 fps sem saltos bruscos.

🥢

Baqueta em CSS Motion Path

As baquetas neon viajam pela crista da onda com offset-path: path(...). A rotação automática offset-rotate: auto 20deg alinha a cabeça percursiva tangencialmente à inclinação da curva em cada instante.

⚡

Zero-JS State Machine

Toda a comutação geométrica e cinemática é orquestrada pela pseudo-classe relacional :has(). Nenhum script bloqueia a linha de execução da renderização gráfica do motor do browser.

PALCO 02 • GRANITE VAULTS

Granite Vaults & Acoustic Impedance

Construídos no século XIX, os arcos em cantaria de granito da Alfândega geram uma reflexão sonora densa e ressonante. Aqui demonstramos como o separador invertido permite interbloquear blocos cromáticos distintos com continuidade matemática perfeita.

🏛️

Arquitetura de Encaixe Perfeito

Para evitar fendas de renderização entre secções contíguas, o topo desta secção utiliza margens negativas margin-top: calc(-1 * var(--path-divider-height)) compensadas com preenchimento interno proporcional.

🎛️

Síntese Modular & Transientes

As transições angulares e em dente-de-serra (808 Sawtooth) espelham a resposta de frequência dos filtros passa-baixo e dos sintetizadores modulares eurorack presentes no festival.

📐

Geometria Não-Destrutiva

Ao contrário de máscaras rasterizadas em formato PNG ou WebP, o corte vetorial por CSS suporta zoom infinito, ecrãs Retina de alta densidade e adapta-se a qualquer formato de ecrã móvel ou ultra-panorâmico.

PALCO 03 • TURNTABLISM OCTAGON

Radial Vinyl Arcs & Scratch Physics

No epicentro do festival, oito gira-discos disputam o troféu de scratch DRUMTIKS '26. O formato de caminho Vinyl Arc demonstra como uma função cúbica de Bézier se aproxima da curvatura de um disco de 33⅓ RPM.

CINEMÁTICA ROTACIONAL

Cálculo do Raio de Curvatura

Quando comuta para o modo Vinyl Arc, os pontos de controlo centrais convergem para as coordenadas (480, 155) e (960, 155) no viewBox do SVG. Isto cria uma curva parabólica com continuidade de tangente suave que simula a borda exterior de um prato de DJ.

CSS Path Engineering & Live Matrix HUD

Inspecione a declaração CSS ativa, a regra matemática de invariância de vértices e a especificidade do seletor em ação. Todos os valores refletem a escolha atual da consola superior.

INSPETOR DE REGRAS CSS VIVAS (LIVE CASCADE MATRIX)
Especificidade: (0, 2, 0) via :root:has() 
/* ==========================================================================
   REGRA CSS ATIVA PARA O SEPARADOR DE SECÇÃO (DRUMTIKS '26)
   Interpolação de coordenadas com paridade de vértices garantida (N = 8)
   ========================================================================== */
.section-clip-morph {
  clip-path: var(--active-polygon);
  transition: clip-path var(--transition-duration-morph) var(--active-ease);
  will-change: clip-path;
}

.drumstick-traveler {
  offset-path: var(--active-motion-path);
  offset-rotate: auto 20deg;
  offset-anchor: 50% 50%;
  transition: offset-path var(--transition-duration-morph) var(--active-ease);
}
