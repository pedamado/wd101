Call to Action - CTA (Chamada para Ação) Call to Action (CTA)

Botão ou elemento visualmente destacado com forte contraste destinado a guiar o utilizador para o objetivo principal. High-contrast dominant button intentionally styled to guide users towards the primary conversion goal.
