Priority+ Navigation (Navegação Prioritária Plus) Priority+ Navigation

Barra de navegação adaptativa que expõe o máximo de itens que cabem no viewport e move automaticamente os excedentes para um menu desdobrável ('Mais...'). Adaptive navigation bar exposing as many items as viewport width permits, progressively overflowing remaining items into a 'More...' dropdown.

Fonte Bibliográfica:Bibliographic Source: Jenifer Tidwell (Designing Interfaces 3rd Ed., Ch. 2: Navigation & Wayfinding) • W3C WAI-ARIA APG (Breadcrumb, Menu, Menubar, Skip Link) • Nielsen Norman Group

<script>
  (function(){
    var btn = document.getElementById('nav03-more');
    var menu = document.getElementById('nav03-menu');
    if(btn && menu){
      btn.onclick = function(){
        var open = menu.hidden;
        menu.hidden = !open;
        btn.setAttribute('aria-expanded', open ? 'true' : 'false');
      };
    }
  })();
</script>

HTML & ARIA

Semântica & AcessibilidadeSemantics & A11y

Barra adaptativa que expõe links essenciais e agrupa excedentes em menu suspenso com aria-expanded. Adaptive navigation showing top links and folding overflow into a dropdown with aria-expanded.

CSS ENGINE

Layout, Variáveis & EstadosLayout & CSS States

Uso de Flexbox e posicionamento absoluto do menu suspenso com z-index. Flexbox layout with absolute dropdown positioning and z-index elevation.

UX & TOUCH

Ergonomia & Alvos TáteisErgonomics & Touch

Garante acesso direto aos principais palcos mesmo em ecrãs compactos sem sobrecarregar a vista. Guarantees direct access to primary stages without visual clutter on intermediate screens.

⚠️ ÉTICA & DARK PATTERNS

Como Evitar a Degradação em Dark Pattern / Anti-Padrão How to Avoid Degenerating into a Dark Pattern / Anti-Pattern

🚨 O Risco de Abuso / Anti-Padrão: 🚨 The Abuse / Anti-Pattern Hazard:

Ocultar intencionalmente termos de reembolso ou acessibilidade no menu excedente ('Mais...') forçando links comerciais. Hiding refund or accessibility options in the overflow menu while promoting paid VIP tiers.

🛡️ Diretrizes de Design Ético & Transparência: 🛡️ Ethical Design & Transparency Guidelines:

  • Priorizar os links com base na frequência de uso dos festivaleiros (Horários, Palcos).Prioritize navigation links strictly by user frequency (Schedule, Stages).
