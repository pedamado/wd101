Toggle Button (Botão de Alternância) Toggle Button

Botão de dois estados (pressionado/não pressionado) que ativa ou desativa uma funcionalidade (ex.: aria-pressed). Two-state action button (pressed/unpressed) toggling modes or features directly on activation (aria-pressed).

Fonte Bibliográfica:Bibliographic Source: Jenifer Tidwell (Ch. 4: Actions & Commands) • W3C WAI-ARIA APG (Button, Dialog, Menu, Toolbar) • Steven Hoober (Designing Mobile Interfaces)
[BUTTON ARIA-PRESSED="TRUE|FALSE" • TOGGLE STATE] 
<div class="drumtiks-toggle-demo">
  <button type="button" class="btn-toggle active" aria-pressed="true" onclick="this.classList.toggle('active'); this.setAttribute('aria-pressed', this.classList.contains('active'))">
    <span class="toggle-indicator">&#9679;</span>
    <span class="toggle-label">Filtro Low-Pass 24dB</span>
  </button>

  <button type="button" class="btn-toggle" aria-pressed="false" onclick="this.classList.toggle('active'); this.setAttribute('aria-pressed', this.classList.contains('active'))">
    <span class="toggle-indicator">&#9675;</span>
    <span class="toggle-label">Distorção Analógica Tube</span>
  </button>
  <span class="xray-badge">[BUTTON ARIA-PRESSED="TRUE|FALSE" &bull; TOGGLE STATE]</span>
</div>

HTML & ARIA

Semântica & AcessibilidadeSemantics & A11y

Uso de aria-pressed='true|false' para anunciar o estado binário ligado/desligado a tecnologias de apoio. WAI-ARIA aria-pressed='true|false' communicates binary toggle state directly to screen readers.

CSS ENGINE

Layout, Variáveis & EstadosLayout & CSS States

Realce visual em ciano com brilho sutil quando ativo, mantendo contraste evidente com o estado inativo. Cyan high-contrast visual cues with subtle glow communicating active synth filter engagement.

UX & TOUCH

Ergonomia & Alvos TáteisErgonomics & Touch

Permite aos festivaleiros ligar e desligar módulos de efeitos sonoros com um toque sem recarregar a interface. Empowers attendees to toggle audio effects on and off instantly without page reloads.

⚠️ ÉTICA & DARK PATTERNS

Como Evitar a Degradação em Dark Pattern / Anti-Padrão How to Avoid Degenerating into a Dark Pattern / Anti-Pattern

🚨 O Risco de Abuso / Anti-Padrão: 🚨 The Abuse / Anti-Pattern Hazard:

Incerteza de estado: ícones ambíguos onde o utilizador não sabe se o estado indicado representa o estado atual ou a ação futura. State ambiguity: confusing icons where users cannot decipher if the label represents current state or next action.

🛡️ Diretrizes de Design Ético & Transparência: 🛡️ Ethical Design & Transparency Guidelines:

  • Indicar inequivocamente tanto visualmente como semanticamente se o efeito está atualmente ativo ou inativo.Unequivocally communicate both visually and programmatically whether the feature is currently active.
