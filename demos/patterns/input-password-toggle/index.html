Password Masking with Toggle (Alternador de Senha) Password Masking with Toggle

Campo de senha com ícone de 'olho' para alternar entre texto oculto e visível, reduzindo erros em mobile. Password input fitted with an accessible eye toggle button allowing users to reveal masked characters on touchscreens.

Fonte Bibliográfica:Bibliographic Source: Jenifer Tidwell (Ch. 5: Getting Input) • Luke Wroblewski (Web Form Design) • W3C WAI-ARIA APG (Checkbox, Combobox, Radio Group, Slider)
[PASSWORD MASKING WITH TOGGLE • DYNAMIC INPUT TYPE • ACCESSIBLE BTN] 
<div class="drumtiks-password-toggle-demo">
  <label for="attendee-pass-input" class="pass-label">Palavra-passe de Acesso à Conta Drumtiks:</label>
  <div class="pass-wrapper">
    <input type="password" id="attendee-pass-input" value="Sintetizador#2026" class="pass-input">
    <button type="button" class="btn-toggle-mask" aria-label="Mostrar ou ocultar palavra-passe" onclick="const i = document.getElementById('attendee-pass-input'); const isP = i.type === 'password'; i.type = isP ? 'text' : 'password'; this.textContent = isP ? 'Ocultar' : 'Mostrar'">
      Mostrar
    </button>
  </div>
  <span class="xray-badge">[PASSWORD MASKING WITH TOGGLE &bull; DYNAMIC INPUT TYPE &bull; ACCESSIBLE BTN]</span>
</div>

🔬 Análise Anatómica do Padrão Anatomical Code Walkthrough

HTML & ARIA

Semântica & AcessibilidadeSemantics & A11y

Alternador de máscara de senha que altera dinamicamente o atributo type entre 'password' e 'text' com botão acessível. Dynamic password masking toggle alternating input type between 'password' and 'text' via accessible button.

CSS ENGINE

Layout, Variáveis & EstadosLayout & CSS States

Botão perfeitamente integrado na extremidade direita do campo sem comprometer os 44px de altura tátil. Seamless right-aligned button maintaining the required 44px tap boundaries.

UX & TOUCH

Ergonomia & Alvos TáteisErgonomics & Touch

Evita erros de digitação em palavras-passe complexas em dispositivos móveis no meio do recinto ruidoso do festival. Drastically reduces frustrating password typos on mobile devices amid hectic festival environments.

⚠️ ÉTICA & DARK PATTERNS

Como Evitar a Degradação em Dark Pattern / Anti-Padrão How to Avoid Degenerating into a Dark Pattern / Anti-Pattern

🚨 O Risco de Abuso / Anti-Padrão: 🚨 The Abuse / Anti-Pattern Hazard:

Ocultar a palavra-passe sem fornecer botão de revelação, provocando bloqueios repetidos de conta. Forbidding password unmasking leading to repeated account lockouts and friction.

🛡️ Diretrizes de Design Ético & Transparência: 🛡️ Ethical Design & Transparency Guidelines:

  • Fornecer sempre o botão de alternância de visibilidade em todos os campos de palavra-passe.Always provide an unmasking visibility toggle on password entry fields.
