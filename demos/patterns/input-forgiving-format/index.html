Forgiving Format (Formato Tolerante) Forgiving Format

Aceitação de formatos diversos de dados pelo sistema sem rejeição imediata, tratando a normalização no backend. Resilient input processing accepting variations (hyphens, spaces, country codes) and normalizing quietly.

Fonte Bibliográfica:Bibliographic Source: Jenifer Tidwell (Ch. 5: Getting Input) • Luke Wroblewski (Web Form Design) • W3C WAI-ARIA APG (Checkbox, Combobox, Radio Group, Slider)

✓ Aceita formatos com ou sem código de país, espaços ou parênteses.
