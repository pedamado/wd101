Filter Bar / Chip Filter (Barra de Filtros em Chips) Filter Bar / Chip Filter

Fileira horizontal de pequenos botões ('chips') acionáveis que ativam ou removem filtros instantaneamente. Horizontal scrollable strip of toggle chips enabling single-tap filter application and immediate visual feedback.

🔬 Análise Anatómica do Padrão Anatomical Code Walkthrough

HTML & ARIA

Semântica & AcessibilidadeSemantics & A11y

Padrão de chips de filtragem acessíveis com botões nativos e atributo aria-pressed comunicando o estado. Accessible filter chips using native button elements paired with aria-pressed state attributes.

CSS ENGINE

Layout, Variáveis & EstadosLayout & CSS States

Formato de pílula circular moderno com flex-wrap para quebra de linha harmoniosa. Pill-shaped touch buttons wrapping smoothly across responsive viewport widths.

UX & TOUCH

Ergonomia & Alvos TáteisErgonomics & Touch

Permite alternar entre palcos com um toque rápido sem abrir menus suspensos secundários. Allows rapid one-touch filtering between stages without diving into deep submenus.

⚠️ ÉTICA & DARK PATTERNS

Como Evitar a Degradação em Dark Pattern / Anti-Padrão How to Avoid Degenerating into a Dark Pattern / Anti-Pattern

🚨 O Risco de Abuso / Anti-Padrão: 🚨 The Abuse / Anti-Pattern Hazard:

Chips que ativam silenciosamente cobranças ou subscrições de newsletters sem consentimento explícito. Weaponizing filter chips to trigger hidden newsletter subscriptions or paid options.

🛡️ Diretrizes de Design Ético & Transparência: 🛡️ Ethical Design & Transparency Guidelines:

  • Chips de filtro devem servir estritamente para alternar a visibilidade de conteúdos.Filter chips must strictly serve content visibility filtering, never mutational actions.
