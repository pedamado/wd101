1.1 Introdução & Enquadramento

O DRUMTIKS '26 é um festival fictício dedicado à cultura do beatmaking analógico, turntablism e hip-hop em vinil sediado nas abóbadas subterrâneas da Alfândega do Porto.

Partindo do protótipo mobile desenhado no Figma pela estudante Joana e a sua equipa, este trabalho tem como meta a sua transposição para a Web real e responsiva em código estritamente estandardizado (HTML5 + CSS3 puro, rigorosamente sem JavaScript).

1.2 Objetivos Pedagógicos de Aprendizagem

  • Arquitetura Multi-Páginas Semântica: Criação de 4 páginas complementares (`index.html`, `dj-warp.html`, `battle-rules.html`, `credits.html`).
  • Abordagem Mobile-First: CSS padrão para pequenos ecrãs com melhoria progressiva (`min-width: 600px` e `min-width: 960px`).
  • Grelha Desktop de 2 Colunas: Palco esquerdo fixo (`position: sticky`) com fluxo de programa e bilhetes à direita.
  • Tipografia Fluida com `clamp()`: Dimensionamento de texto orgânico adaptado à largura do ecrã sem saltos bruscos.
  • Direção de Arte Fotográfica: Múltiplos rácios de aspeto (16:9, 1:1, 9:16) via `` com WebP e JPEG.
  • Vendorização de Webfonts: Autohospedagem local de ficheiros WOFF2 de fontes variáveis em `assets/fonts/`.
  • Padrões Pure CSS Avançados: Simulador de preços reativo com `:root:has()`, barra de leitura com `animation-timeline: scroll()`, carrossel de fotos com scroll-snap e acordeão articulado com `
    `.

Arquitetura CSS3, Design Tokens & Tipografia Fluida clamp()

3.1 Orquestração Modular com @layer

Para controlar a especificidade sem recorrer a !important, declaramos formalmente a cascata de camadas:

@layer reset, fonts, theme, base, layout, components, gallery, accordion, subpages, simulator, modals, animations, utilities;

3.2 Tipografia Fluida com a Função clamp()

A fórmula clamp(min, preferred, max) garante que os títulos crescem proporcionalmente à largura do ecrã, mantendo legibilidade sem provocar quebras indesejadas:

--text-size-hero-title: clamp(1.6rem, 1rem + 2.5vw, 2.5rem);
--text-size-artist-page-title: clamp(1.75rem, 4vw, 3.25rem);
--text-size-sim-price: clamp(1.6rem, 1.2rem + 1.8vw, 2.4rem);

Design Responsivo Mobile-First & Direção de Arte Fotográfica

4.1 Breakpoints de Largura Mínima (min-width)

Regra de Ouro da UC: O CSS padrão aplica-se a ecrãs de smartphone (<600px). Nunca utilize max-width para desenhar a estrutura principal. Escale progressivamente usando min-width.
  • Default (< 600px): Coluna única, barra de compra sticky na base.
  • Tablet (min-width: 600px): Alargamento de margens, galeria a 2 colunas.
  • Desktop (min-width: 960px): Grelha de 2 colunas (palco sticky à esquerda, fluxo dinâmico à direita).

4.2 Direção de Arte com <picture>

O elemento <picture> permite trocar o enquadramento fotográfico consoante a proporção do ecrã:

<picture>
  <!-- 16:9 Panorâmica para Widescreen Desktop -->
  <source media="(min-width: 1024px)" type="image/webp" 
          srcset="assets/images/dj-warp-vault-16x9-960w.webp 960w, assets/images/dj-warp-vault-16x9-1400w.webp 1400w" 
          sizes="(min-width: 1240px) 1160px, 92vw">

  <!-- 1:1 Quadrado para Tablet -->
  <source media="(min-width: 600px)" type="image/webp" 
          srcset="assets/images/dj-warp-vault-1x1-600w.webp 600w, assets/images/dj-warp-vault-1x1-960w.webp 960w" 
          sizes="85vw">

  <!-- 9:16 Vertical para Smartphone -->
  <source type="image/webp" 
          srcset="assets/images/dj-warp-vault-9x16-400w.webp 400w, assets/images/dj-warp-vault-9x16-600w.webp 600w" 
          sizes="100vw">

  <img src="assets/images/dj-warp-vault-16x9-960w.jpg" alt="DJ Warp no cofre da Alfândega" width="1200" height="675" loading="lazy">
</picture>

Padrões Interativos Pure CSS (Sem JavaScript)

5.1 Barra de Leitura com Scroll-Driven Animation

.scroll-progress-bar {
  position: fixed; top: 0; left: 0; width: 100%; height: 4px;
  background: linear-gradient(90deg, #e60000 0%, #8a2be2 100%);
  transform-origin: 0% 50%;
  transform: scaleX(0);
  z-index: 9999;
}
@supports (animation-timeline: scroll()) {
  .scroll-progress-bar {
    animation: growProgressBar auto linear;
    animation-timeline: scroll(root);
  }
  @keyframes growProgressBar {
    from { transform: scaleX(0); }
    to { transform: scaleX(1); }
  }
}

5.2 Acordeão Articulado com <details> e CSS Grid

.accordion-body-grid {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 0.35s cubic-bezier(0.4, 0, 0.2, 1), opacity 0.3s ease;
  opacity: 0;
}
.accordion-item[open] .accordion-body-grid {
  grid-template-rows: 1fr;
  opacity: 1;
}
