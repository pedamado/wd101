Desmistificando a Sintaxe animation-range

Enquanto a timeline scroll(root) observa a página inteira, a timeline view() calcula a posição relativa do elemento relativamente à janela de visualização do utilizador:

/* 1. Atribuição da Timeline de Visualização */ .reveal-card { animation: revealOnViewportEntry auto linear both; animation-timeline: view(); } /* 2. Definição dos Pontos de Início e Fim da Interpolação */ /* Inicia quando 15% do elemento entra no ecrã (entry 15%) */ /* Termina quando o elemento preenche 40% da área visível (cover 40%) */ .reveal-card { animation-range: entry 15% cover 40%; } /* 3. Interpolação Limpa e Sem Recálculos de Layout (GPU Accelerated) */ @keyframes revealOnViewportEntry { 0% { opacity: 0; transform: translateY(60px) scale(0.92); filter: blur(6px); } 40% { opacity: 0.6; transform: translateY(20px) scale(0.97); filter: blur(2px); } 100% { opacity: 1; transform: translateY(0) scale(1); filter: blur(0); } }
