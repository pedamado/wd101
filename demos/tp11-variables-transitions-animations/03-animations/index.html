Barra de Progresso com Scroll Total

Observa a barra de leitura colorida fixa no topo da janela. À medida que percorres o documento, ela expande-se de 0% a 100% através da propriedade CSS animation-timeline: scroll(root), eliminando por completo a necessidade de event listeners de scroll em JavaScript.

Como funciona a Timeline scroll(root)

O seletor @supports (animation-timeline: scroll()) verifica o suporte moderno do motor do browser. A animação advanceTotalScroll interpola scaleX(0) até scaleX(1) ancorada no scrollbar raiz da janela (root).

Código CSS da Barra de Progresso

.scroll-progress-bar {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 6px;
  background: linear-gradient(90deg, #e60000, #ff5e3a, #8a2be2);
  transform-origin: 0% 50%;
  transform: scaleX(0);
  z-index: 1000;

  /* Sincronização direta com a raiz do documento */
  animation: advanceTotalScroll linear both;
  animation-timeline: scroll(root);
}

@keyframes advanceTotalScroll {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}
