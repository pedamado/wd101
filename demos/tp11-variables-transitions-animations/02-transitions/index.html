Como funcionam as Transições CSS neste Carrossel

As microinterações de hover nos cartões e nos botões de paginação recorrem à propriedade combinada transition. O CSS interpola estados entre o repouso e o estado ativo:

1. Elevação e Sombra do Cartão

.carousel-slide {
  transition:
    transform 0.4s cubic-bezier(0.16, 1, 0.3, 1),
    box-shadow 0.4s cubic-bezier(0.16, 1, 0.3, 1),
    border-color 0.3s ease;
}

.carousel-slide:hover {
  transform: translateY(-8px) scale(1.02);
  border-color: #e60000;
}

2. Zoom da Imagem de Capa

.slide-img {
  transition:
    transform 0.6s cubic-bezier(0.25, 1, 0.5, 1),
    filter 0.4s ease;
}

.carousel-slide:hover .slide-img {
  transform: scale(1.08);
  filter: brightness(1.1);
}

3. Paginação Reativa

.nav-dot {
  transition:
    transform 0.25s cubic-bezier(0.34, 1.56, 0.64, 1),
    background-color 0.25s ease,
    border-color 0.25s ease;
}

.nav-dot:hover {
  transform: scale(1.1);
}
