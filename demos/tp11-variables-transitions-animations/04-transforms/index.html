Transformações CSS: Posição, Tamanho, Rotação & Origem

As Transformações CSS (transform) alteram a geometria visual de um elemento no espaço 2D ou 3D sem afetar a posição dos elementos vizinhos no fluxo normal do documento. Este laboratório permite-te experimentar as funções cardinais e compreender a importância do ponto de apoio (transform-origin).

Como o Browser Calcula esta Transformação

Observa a caixa tracejada (posição física estática) em contraste com o elemento sólido (posição transformada). Repara como o ponto vermelho (o transform-origin) funciona como o eixo ou agulha da rotação!

/* Regra CSS Aplicada ao Elemento */ .stage-target { /* 1. Define o ponto de pivot / ancoragem */ transform-origin: var(--lab-origin-x) var(--lab-origin-y); /* 2. Executa a lista ordenada de transformações */ transform: translate(var(--lab-translate-x), var(--lab-translate-y)) scale(var(--lab-scale)) rotate(var(--lab-rotate)) skewX(var(--lab-skew-x)); /* 3. Aceleração gráfica por hardware na GPU */ transition: transform 0.5s cubic-bezier(0.34, 1.56, 0.64, 1); }
💡 Regra de Ouro: A ordem das funções na propriedade transform altera o resultado final, porque cada operação afeta o sistema de coordenadas local da operação seguinte!

Compêndio Técnico: As 4 Operações de Transform

1. Posição (Translation)

Move o elemento horizontalmente e verticalmente. Ao contrário de top/left, o translate() não força o browser a recalcular o layout da página, sendo executado com 60/120 FPS pela placa gráfica.

translate(x, y)
translate3d(x, y, z)

2. Tamanho (Scaling)

Modifica as dimensões aparentes do elemento multiplicando a sua largura e altura por um fator escalar. Valores entre 0 e 1 reduzem o elemento; valores superiores a 1 ampliam-no.

scale(fator)
scaleX() / scaleY()

3. Rotação (Rotation)

Gira o elemento em torno do ponto de ancoragem definido por transform-origin. Suporta unidades angulares como graus (deg), radianos (rad) ou voltas (turn).

rotate(45deg)
rotateZ(0.5turn)

4. Inclinação (Skewing)

Distorce os eixos retangulares do elemento num paralelogramo, simulando superfícies com ângulo obliquo, tipografia em itálico agressivo ou cartões tridimensionais inclinados.

skew(x-angle, y-angle)
skewX(-15deg)
