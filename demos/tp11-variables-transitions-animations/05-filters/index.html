Efeitos de Filtro CSS: Cor, Desfoque & Composição Gráfica

A especificação de CSS Filters (filter e backdrop-filter) disponibiliza operações gráficas comparáveis às de software de edição fotográfica diretamente no navegador. Permite ajustar exposição, matiz, saturação, criar desfoques ópticos e produzir sombras com recorte alfa fiel via drop-shadow().

Processamento Gráfico e Matrizes de Cor

O motor CSS executa uma passagem de shader no raster da imagem. Ao contrário de recalcular estilos geométricos, os filtros são calculados pixel-a-pixel por aceleração GPU.

/* Regra CSS Aplicada à Imagem */ .filtered-artwork { /* Filtro ativo interpolado suavemente */ filter: var(--active-filter); /* Transição de interpolação entre estados de filtro */ transition: filter 0.4s ease; }
💡 Encadeamento (Chaining): Podes encadear vários filtros separando-os por espaços (ex: filter: brightness(1.2) contrast(1.4) blur(1px);). A ordem afeta o resultado final!

Distinção Fundamental: box-shadow versus filter: drop-shadow()

Um dos erros mais comuns no desenvolvimento frontend é tentar aplicar sombra a um ícone vetorial SVG ou imagem transparente com box-shadow. O box-shadow cria uma sombra quadrada em torno da caixa retangular do elemento. O filter: drop-shadow(), pelo contrário, respeita os contornos reais dos píxeis opacos (canal alfa)!

1. Com box-shadow (Caixa Rígida)

❌ A sombra projeta-se em torno do retângulo exterior da tag <svg>, arruinando o recorte circular do disco de vinil.

2. Com filter: drop-shadow() (Recorte Alfa Fiel)

✅ A sombra contorna perfeitamente a circunferência do vinil vazado, adaptando-se com precisão à transparência!

Catálogo das Funções de Filtro CSS

blur(raio)

Desfoca os píxeis com distribuição gaussiana. Ideal para fundos desfocados (depth of field) ou modais modulares.

filter: blur(8px);

brightness(fator)

Multiplicador de luminosidade. Valores abaixo de 1 escurecem; acima de 1 iluminam.

filter: brightness(1.5);

contrast(fator)

Altera a amplitude entre os valores mais escuros e mais claros da imagem.

filter: contrast(2.0);

hue-rotate(ângulo)

Roda todas as cores ao longo da roda cromática de 0deg a 360deg.

filter: hue-rotate(90deg);

grayscale(percentagem)

Remove a saturação transformando a paleta em tons neutros de cinzento.

filter: grayscale(100%);

backdrop-filter

Aplica o efeito aos elementos situados atrás do elemento atual (efeito vidro fosco / glassmorphism).

backdrop-filter: blur(12px);
