Inspector de Variáveis CSS & Dinâmica de Tema

Clica nos botões Auto, Claro e Escuro no menu superior. O CSS usa a função light-dark() combinada com a declaração color-scheme: light dark.

Variável CSS (Token) Expressão CSS Papel Semântico & Permutação
--bg-canvas light-dark(#f4f4f7, #0a0a0c) Fundo global do documento (aplicado no <body>)
--bg-surface light-dark(#ffffff, #16171a) Fundo dos cartões e cabeçalho da página
--text-primary light-dark(#111216, #f4f4f6) Títulos de alta ênfase e logótipo
--text-secondary light-dark(#4a4d57, #a2a6b2) Corpo de texto e descrições dos artigos
--accent-primary #e60000 Cor primária do festival DRUMTIKS (estática)
--border-subtle light-dark(rgba(0,0,0,0.12), rgba(255,255,255,0.12)) Fronteiras e divisores estruturais
--theme-transition all 0.35s cubic-bezier(0.4, 0, 0.2, 1) Interpolação contínua entre temas sem flicker
