Perguntas Frequentes (FAQ)

Como funciona a entrada e a pulseira RFID do festival?

À entrada na Alfândega do Porto, o seu bilhete digital ou físico é trocado por uma pulseira inteligente RFID à prova de água. A pulseira serve tanto para acesso rápido às portas como para carregamentos cashless de restauração e merchandising.

É fornecida proteção auditiva aos participantes?

Sim! A proteção da audição é prioridade máxima no DRUMTIKS. Em todas as entradas dos palcos Arcos de Granito e Octágono Vinil são distribuídos gratuitamente protetores auriculares de atenuação acústica linear com filtro de -19dB.

Como chegar à Alfândega do Porto por transportes públicos?

A Alfândega é servida diretamente pela Linha 500 da STCP (autocarros de dois andares com vista panorâmica do rio) e pelo Elétrico Histórico Linha 1. Se vier de comboio, desça na estação de São Bento e apanhe a ligação ribeirinha em 10 minutos a pé.

PADRÃO 05

Animação Fluida de Altura com interpolate-size

MDN interpolate-size ↗

Durante mais de duas décadas, animar transições de height: auto foi considerado a "pedra no sapato" do CSS. A nova especificação W3C CSS Values and Units Level 4 resolve este dilema definitivamente através de interpolate-size: allow-keywords no elemento raiz: 

/* 1. Ativação Global no Root */
:root {
  interpolate-size: allow-keywords; /* Permite transitar para palavras-chave como 'auto' */
}

/* 2. Acordeão Nativo HTML5 Sem JavaScript */
.accordion-item {
  overflow: hidden;
  transition: border-color 200ms ease, box-shadow 200ms ease;
}

/* 3. Conteúdo Expansível com Transição */
.accordion-content {
  transition: block-size 350ms var(--ease-spring), opacity 350ms ease;
}

/* 4. Rotação do Ícone Chevron */
.accordion-item[open] .accordion-chevron {
  transform: rotate(180deg);
}
