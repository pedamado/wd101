PADRÃO 07

Máquina de Estados com :has() & Diálogo <dialog>

MDN :has() ↗

A pseudo-classe :has() (muitas vezes descrita como o "seletor pai") permite que o estado de um rádio no DOM altere propriedades CSS em nós completamente separados. O elemento <dialog> é renderizado na camada de topo do browser (top layer), garantindo que nada sobrepõe a modal: 

/* 1. Máquina de Estados: Injeção de Preço Dinâmico via CSS */
:root:has(#ticket-pass-day:checked) .summary-total-price::after {
  content: "45 €";
}

:root:has(#ticket-pass-vip:checked) .summary-total-price::after {
  content: "160 €";
}

/* 2. Janela Modal no Top-Layer Nativo com Backdrop Blur */
dialog.ticket-dialog {
  margin: auto;
  border-radius: var(--radius-lg);
  box-shadow: var(--shadow-lg);
}

dialog.ticket-dialog::backdrop {
  background: rgba(0, 0, 0, 0.75);
  backdrop-filter: blur(8px); /* Desfocagem de fundo de cinema */
}
