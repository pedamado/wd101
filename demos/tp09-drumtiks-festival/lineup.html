PADRÃO 03

Espaço 3D, Perspetiva & Seletores Adjacentes

MDN perspective ↗

O segredo da caixa de discos em leque reside na combinação de perspective: 1200px no contentor pai com a preservação do espaço 3D (transform-style: preserve-3d) e o seletor de irmãos seguintes :hover ~ .vinyl-record, que afasta os discos posteriores automaticamente: 

/* 1. Contexto de Projeção 3D */
.vinyl-crate-viewport {
  perspective: 1200px;
  perspective-origin: 50% 30%;
}

/* 2. Preservação do Espaço Tridimensional */
.vinyl-crate-track {
  display: flex;
  transform-style: preserve-3d;
}

/* 3. Disco em Foco: Salta para o Viewport (+80px) */
.vinyl-record:hover {
  transform: rotateY(0deg) translateZ(80px) scale(1.08);
  z-index: 20;
}

/* 4. Abertura em Leque dos Discos Seguintes (Zero-JS) */
.vinyl-record:hover ~ .vinyl-record {
  transform: rotateY(22deg) translateZ(-40px) translateX(40px);
}
