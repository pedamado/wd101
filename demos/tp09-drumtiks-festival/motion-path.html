PROPAGAÇÃO ACÚSTICA

CSS Motion Path & Dinâmica de Mola

Antigamente, guiar um elemento visual ao longo de curvas de Bézier exigia bibliotecas pesadas de JavaScript. Hoje, a especificação W3C CSS Motion Path (offset-path) permite que qualquer elemento HTML navegue caminhos paramétricos com rotação automática tangencial ao declive.

PADRÃO 04

CSS Motion Path & Função Spring linear(...)

MDN offset-path ↗

A propriedade offset-path define o caminho SVG que o elemento percorre. Com offset-rotate: auto, o navegador calcula matematicamente a rotação tangencial da baqueta em cada micro-ponto do percurso. O ressalto físico de mola é gerado inteiramente na GPU através de uma curva pontual linear(...) sem necessidade de animação em JavaScript: 

/* 1. Definição do Percurso Paramétrico */
.motion-sound-sprite {
  offset-path: path('M 30,180 C 120,40 260,340 380,180 C 500,20 680,320 800,160 C 920,40 1060,260 1180,180');
  offset-rotate: auto; /* Orienta o elemento tangencialmente à curva */
  animation: travel-motion-path 6s infinite alternate;
  animation-timing-function: var(--ease-spring); /* Função linear() com overshoot */
}

/* 2. Keyframes de Distância Percorrida */
@keyframes travel-motion-path {
  0%   { offset-distance: 0%; }
  100% { offset-distance: 100%; }
}
