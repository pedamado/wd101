CSS Grid vs. CSS Flexbox: Mental Model & Decision Matrix

Pedagogical reference for WD101 students: Choosing the optimal layout tool based on dimensional constraints, content requirements, and architectural scope.

Criteria / Dimension CSS Flexbox CSS Grid Container Queries (@container)
Dimensional Scope One-Dimensional (1D)
Calculates along a single axis at a time (row OR column).		 Two-Dimensional (2D)
Controls horizontal columns AND vertical rows simultaneously.		 Component-Scoped (1D or 2D)
Queries the immediate parent container width (inline-size), not viewport.
Primary Architectural Role Micro-Layout
Component internals, navigation menus, audio controls, tag pill badges, button groups.		 Macro-Layout
Overall page skeleton, hero/sidebar/main grids, complex editorial magazine spreads.		 Modular Component Responsiveness
Self-contained cards/widgets adapting seamlessly wherever dropped (sidebar vs main).
Sizing Paradigm Content-First (Intrinsic)
Item sizes naturally dictate space allocation via flex-basis and text width.		 Container-First (Extrinsic)
The parent grid tracks dictate cell dimensions via fr, minmax(), and repeat().		 Context-First (Intrinsic Container)
Children query cqi units and container width breakpoints without global media queries.
Responsive Query Method Viewport @media queries required for global reorganization. Viewport @media queries required for global reorganization. @container (min-width: ...)
No global viewport queries! Zero cross-page selector coupling.
Wrapping Behavior Items wrap onto new lines, but each line distributes free space independently of other lines. Items stay strictly aligned to the established column and row matrix tracks. Component morphs layout type: Flex column (<440px) ➔ Flex row ➔ 2D Grid (740px+).
Visual Reordering order: <number> (visual only; preserves DOM accessibility order). Explicit coordinates (grid-column, grid-row, grid-area) or grid-auto-flow: dense. Reordering handled contextually per container size slot.
