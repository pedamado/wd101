/* ==========================================================================
   MOBILE FIRST BASE (Single Column Stack)
   ========================================================================== */
.discography-grid-stage {
  display: grid;
  grid-template-columns: 1fr;     /* 1 column taking 100% width on mobile */
  gap: 1.5rem;                    /* Uniform row and column gap */
}

/* ==========================================================================
   VARIATION 1: MODULAR (EQUAL UNITS)
   ========================================================================== */
@media (min-width: 900px) {
  body:has(#grid-var-modular:checked) .discography-grid-stage {
    grid-template-columns: repeat(4, 1fr);   /* 4 equal fractional columns */
    grid-auto-rows: minmax(260px, auto);     /* Rows auto-expand to content */
  }

  /* Full LPs occupy 2 columns (larger areas) */
  body:has(#grid-var-modular:checked) .album-warp-theory {
    grid-column: span 2;
    grid-row: span 2;
  }
  body:has(#grid-var-modular:checked) .album-concrete-pulse { grid-column: span 2; }
  body:has(#grid-var-modular:checked) .album-dust-grooves    { grid-column: span 2; }

  /* EPs occupy 1 column (compact satellite areas) */
  body:has(#grid-var-modular:checked) .album-fader-kinetics { grid-column: span 1; }
  body:has(#grid-var-modular:checked) .album-circuit-bender { grid-column: span 1; }
}

/* ==========================================================================
   VARIATION 2: MODULAR WITH INTENTIONAL NEGATIVE SPACE (EMPTY CELLS)
   ========================================================================== */

Pedagogical Cheat Sheet

Barebone Structural Blueprint: Pure CSS Grid

Summary of Structural Requirements: CSS Grid is a 2-dimensional layout tool. To build responsive modular and asymmetric layouts, you establish tracks on the Grid Container (columns and rows) and position Grid Items using coordinate spans (grid-column: span 2), explicit line boundaries (grid-column: 1 / 3), or the auto-placement packing algorithm (grid-auto-flow: dense). No decorative styling (colors, fonts, borders, shadows) is needed for the grid matrix to operate.

1. Barebone HTML5 Landmarks HTML 
<!-- Landmark: Main Content -->
<main>

  <!-- Landmark: Section acting as 2D Grid Container -->
  <section class="grid-container">

    <!-- Landmark: Article acting as Dominant Item (LP) -->
    <article class="grid-item item-dominant">
      <h3>Large Item 1 (Spans 2x2)</h3>
      <p>Content...</p>
    </article>

    <!-- Landmark: Compact Satellite Item (EP) -->
    <article class="grid-item item-compact">
      <h3>Small Item 2 (Spans 1x1)</h3>
      <p>Content...</p>
    </article>

    <!-- Deliberate Negative Space Void -->
    <div class="grid-void" aria-hidden="true"></div>

    <!-- Landmark: Aside acting as Editorial Span -->
    <aside class="grid-item item-wide">
      <p>Editorial Callout / Quote...</p>
    </aside>

  </section>

</main>
2. Core Structural Selectors & Properties CSS (Zero Visual Fluff) 
/* 1. CONTAINER LEVEL (Columns, Rows & Packing) */
.grid-container {
  display: grid;
  grid-template-columns: 1fr;     /* Mobile single column */
  gap: 1.5rem;
}

@media (min-width: 900px) {
  /* Variation 1: Modular Equal Units */
  .grid-container.mode-modular {
    grid-template-columns: repeat(4, 1fr);
    grid-auto-rows: minmax(200px, auto);
  }

  /* Variation 2: Asymmetric Tracks + Dense Packing */
  .grid-container.mode-asymmetric {
    grid-template-columns: 1.2fr 2fr 1fr 1.5fr; /* Non-uniform widths */
    grid-auto-flow: dense;        /* Backfills unoccupied slots */
  }
}

/* 2. ITEM LEVEL (Line Placement & Spanning) */
.item-dominant {
  grid-column: span 2;            /* Spans 2 horizontal tracks */
  grid-row: span 2;               /* Spans 2 vertical tracks */
}

.item-compact {
  grid-column: span 1;            /* Standard 1-cell footprint */
}

.item-wide {
  grid-column: 1 / -1;            /* Spans all columns edge-to-edge */
}

/* Coordinate-based Negative Space */
.grid-void {
  grid-column: 3 / 4;             /* Leaves slot unoccupied by content */
}

Pedagogical Anatomy: The CSS Grid Engine

1. Two-Dimensional Orchestration

Unlike Flexbox (which is 1D), CSS Grid manages columns and rows simultaneously. A grid item can span multiple columns (grid-column: span 2) and multiple rows (grid-row: span 2), creating hierarchical graphic design layouts without nested wrapper divs.

2. The fr Unit & minmax()

The fr (fractional unit) allocates free space proportionally. Combined with minmax(260px, 1fr), it guarantees elements never collapse below a legible minimum width while expanding fluidly into surplus space.

3. grid-auto-flow: dense

By default, Grid places items in strict DOM order. With grid-auto-flow: dense, the browser's auto-placement algorithm backtracks to fill empty voids left behind when larger spanning cards move down, creating tight, dynamic masonry-style compositions.

4. Shorthand vs Longhand Syntax

• Shorthand: grid-column: 1 / 3;
• Longhand: grid-column-start: 1; grid-column-end: 3;
Both denote the starting grid line and ending grid line (not the cell count). Line 1 is the leftmost edge, and -1 represents the rightmost edge of explicit tracks!
